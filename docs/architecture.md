## Database Schema

```text
User
 ├── Note (title, content, created, updated)
 │    ├── Tag (many-to-many)
 │    └── Category (foreign key)
 │
 ├── Document (title, file, page_count, uploaded)     [Vault]
 │    └── Category (foreign key)
 │
 ├── Resource (title, url, type, saved)               [Vault]
 │    └── Category (foreign key)
 │
 ├── Chunk (content, source_type, source_id, vector)  [RAG]
 │
 ├── ChatConversation → ChatMessage (role, content)   [RAG]
 │
 ├── TopicMastery (topic_name, confidence, next_review) [Learning]
 │    ├── TopicSource (Generic FK to Document/Note)
 │    └── ReviewItem (FK to TopicMastery, SET_NULL)
 │
 ├── ReviewSession (score, total_items, completed_at)   [Learning]
 │    └── ReviewItem (question, options, user_answer)
 │
 ├── Claim (claim_text, evidence, source, embedding)  [Graph - P5]
 │    └── Vector embedding (1024 dims) for semantic similarity
 │
 ├── TopicRelationship (source, target, type)         [Graph - P5]
 │
 └── Contradiction (claim_a, claim_b, severity, is_resolved) [Intelligence - P6.1]
      ├── Explanation of conflict generated by LLM
      └── Resolution note and timestamp
```

## API Structure

```text
/api/
├── /auth/
│    ├── POST /register/
│    ├── POST /token/          (returns access + refresh token)
│    └── POST /token/refresh/
│
├── /notes/
│    ├── GET/POST    /
│    ├── GET/PUT/DELETE /{id}/
│    ├── GET /categories/
│    └── GET /tags/
│
├── /vault/
│    ├── POST /documents/
│    ├── GET  /documents/
│    ├── GET/POST /resources/
│    └── GET /search/?q=...
│
├── /rag/
│    ├── POST /chat/
│    ├── GET  /conversations/
│    └── GET  /search/?q=...   (semantic search)
│
├── /learning/
│    ├── GET  /topics/
│    ├── GET  /topics/{id}/
│    ├── GET  /daily-review/
│    └── POST /submit-answer/
│
├── /graph/
│    ├── GET /network/         (interactive 2D graph data)
│    └── GET /analyze-gap/     (prerequisite BFS & blind spots)
│
└── /intelligence/             [Phase 6.1 — Contradiction Radar]
     ├── GET  /                (list contradictions with ?status filter)
     ├── PATCH /{id}/resolve/  (reconcile knowledge conflict)
     └── GET  /stats/          (unresolved contradiction count for dashboard)
```
